# ENEXUR Global Market Access OS™ prototype

A responsive, static SaaS prototype built as a single-page HTML application. No build step, backend, credentials, or API keys are required.

## Open locally

Open `index.html` in a current desktop or mobile browser. For local HTTP preview, serve this folder with any static web server.

## Publish as a shareable link

Upload `index.html` to any static hosting provider (GitHub Pages, Netlify, Cloudflare Pages, or an existing web host). The published site can then be opened from any device with the URL. This package does not include an account or deployment credentials and has not been published yet.

## Demo and security notes

- All organizations, people, scores, signals, and commercial values are fictional demo data.
- No CRM or external integration is connected; integration statuses are architecture/demo states.
- Outreach controls simulate actions and do not send messages.
- Do not enter confidential or personal information. This is a client-side prototype without authentication, tenant isolation, persistence, or a production backend.
- No API credentials are present in the prototype.
